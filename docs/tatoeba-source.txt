The upstream plugin is GPL-3.0. Its original main.js contained an undefined
variable and attempted to push into a string while parsing API results. This
build applies a small local parser fix and HTML-escapes returned sentence text.
The upstream LICENSE is included with the staged plugin, and the top-level
LICENSE contains the GPLv3 text.

https://api.tatoeba.org/v1/sentences

Tatoeba content is subject to Tatoeba's attribution and Creative Commons
licensing terms. Review the service's current terms before redistributing
returned example content.
