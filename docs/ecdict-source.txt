ECDict portable database notice

This folder contains a compact SQLite projection of the Pot App ECDict plugin database.

Plugin source:
https://github.com/pot-app/pot-app-translate-plugin-ecdict
Release source used by the preparation script (2.0.1):
https://github.com/pot-app/pot-app-translate-plugin-ecdict/releases/download/2.0.1/plugin.com.pot-app.ecdict.potext

Original ECDict project:
https://github.com/skywind3000/ECDICT

columns used by Pot. The source plugin is the GPLv3 project `pot-app-translate-plugin-ecdict`
